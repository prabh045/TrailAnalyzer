# TrailAnalyzer: Import models with Core ML

Use Core ML to import a machine learning model into your app. Add the model you trained in Train a Core ML model to a new app that takes details about hikes and displays their likely challenge level.

## Overview

These resources are associated with the [Import models with Core ML
](https://developer.apple.com/tutorials/develop-in-swift/custom-models-with-core-ml) tutorial. This is part of the [Machine learning and AI](https://developer.apple.com/tutorials/develop-in-swift/welcome-to-machine-learning-and-ai) tutorials from [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) by Apple.

## Using these resources

Follow the tutorial instructions in section one of [Import models with Core ML](https://developer.apple.com/tutorials/develop-in-swift/custom-models-with-core-ml) to use these resources within the Xcode app.
